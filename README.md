## Release Notes
- **Enhanced Library Organization:** Category filter chips (*All*, *Newspapers*, *Editorials*, *Magazines*, *Books*, *International*) with dynamic badge counts.
- **Search & Quick Filter:** Real-time search by newspaper title, magazine name, and edition date.
- **Multi-Select & Batch Actions:** Long-press to enter selection mode, batch delete with total MB freed summary, batch share, and select all/deselect all.
- **Smart Sorting:** Flexible sorting by newest date, oldest date, alphabetical (A to Z), and file size (largest/smallest).
- **Reading Progress Tracking:** Instant reading continuity showing last read page badge on cards.
- **Jugantor Master Downloader & Prioritized Catalog:** Preserved high-resolution print engines and optimized top recognized newspaper order.
